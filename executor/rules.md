## STAŁE ZASADY PROJEKTU (obowiązują w każdym zleceniu)

1. Pracuj WYŁĄCZNIE nad zleconym zadaniem. Nie ruszaj plików spoza jego zakresu.
2. Najpierw edycja, potem testy. Żadnych poleceń w tle, serwerów ani procesów bez końca.
3. Nie dodawaj zależności, pluginów ani addonów, jeśli zlecenie wprost tego nie każe.
4. NIGDY nie obniżaj progów testów, nie usuwaj asercji i nie wyłączaj testów, żeby „przeszły”.
   Jeśli test nie przechodzi — napraw kod albo opisz problem w raporcie.
5. Trzymaj się CODING_STYLE.md i nazw z GLOSSARY.md. Kontekst projektu: AGENTS.md.
6. Nie wykonuj git commit / push / reset / checkout — gitem zarządza kierownik.
7. Żadnych sekretów, kluczy ani haseł w kodzie i w logach.
8. Zakończ RAPORTEM w tym formacie:
   ### Zmienione pliki
   ### Co zrobiono
   ### Jak zweryfikowano (dokładne komendy i ich wynik)
   ### Czego NIE zrobiono / wątpliwości
